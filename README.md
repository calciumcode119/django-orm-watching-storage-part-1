# Пульт охраны банка
Это внутренний репозиторий для сотрудников банка. Если вы попали в него случайно, вы не сможете его запустить, так как у вас нет доступа к БД.

Пульт охраны - это сайт, который можно подключить к удалённой БД с визитами и карточками сотрудников банка.

### Как установить
Для начала работы достаточно установить необходимые библиотеки из requirements.txt, заполнить адрес и пароль БД в settings.py и запустить main.py. 

### Для чего нужен
При запуске в консоль выведется общее количество пропусков и сколько из них сейчас активны.

### Цель проекта
Код написан в образовательных целях на онлайн-курсе для веб-разработчиков dvmn.org.
